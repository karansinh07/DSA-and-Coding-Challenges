# DSA & Coding Challenges

Daily data-structures-and-algorithms practice, in JavaScript. One problem a day, organized by topic, so progress is visible right here on GitHub.

**Why this repo exists:** consistent DSA practice is one of the best ways to get interview-ready and to show recruiters/hiring managers real, committed problem-solving — not just a resume line. Every commit here is a solved problem.

Connect with me on LinkedIn: **[https://www.linkedin.com/in/karansinh-rajput-706a91398](https://www.linkedin.com/in/karansinh-rajput-706a91398)**

## How I use this repo

1. Open the next unsolved `.js` file under `LeetCode-75/`.
2. Each file has the problem's topic, difficulty, a short description, and a link to the exact problem on LeetCode at the bottom.
3. Solve it on LeetCode first, until it's **Accepted**.
4. Paste the accepted solution into the file, replacing the placeholder comment.
5. Commit with a message like `Day N: <Problem Title>` and move to the next one.

One problem a day keeps this green and keeps the skills sharp.
